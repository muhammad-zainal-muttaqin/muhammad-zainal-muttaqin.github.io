Fruit bunch detector

This is the YOLO26n detector our lab ships in the PalmAnnotate field app, trained on the SawitMVC dataset (953 trees, 3,992 photos), running in your browser with ONNX Runtime Web. The photos are from a field capture in November 2026 that it was not trained on. It grades each bunch from B1 (ripe) to B4 (unripe).

Other trees

B1 is ripe, B4 is unripe (SawitMVC grading). Telling neighbouring grades apart is harder than finding the bunch, so B1/B2 and B2/B3 mix-ups still happen.

Runs locally with WebGPU, or WebAssembly where WebGPU is not available. Uploaded photos are not sent anywhere. You can also drag a photo onto the image.

Selected work

  1. Sawit Vision API

    2026 · Personal project

    A REST service for fruit bunch detection. It serves our lab's YOLO26n detector (trained on SawitMVC, ripeness grades B1–B4) through ONNX Runtime, with pre- and post-processing rewritten in NumPy so it runs without PyTorch; every request is logged to SQLite. I compared it with an older YOLOv8n model on 568 new field photos: it put 2 boxes on ground or trunk where the old model put 216, and it grades ripe red bunches as B1 where the old one called them underripe.

    Python, ONNX Runtime, FastAPI, SQLite, pytest, Docker

  2. Counting bunches across tree photos

    2026 · Research, ULM · paper at IEEE ICIC 2026 (first author)

    Each tree is photographed from 4 to 8 sides, so one bunch shows up in several photos. I compared ways to merge those duplicates on 953 trees from two plantations, keeping the detector fixed. With ground-truth features an SVM gets the count right within ±1 bunch for 96.1% of trees; the best hand-written rule gets 87.6%; the full pipeline from raw detector output gets 71.6%.

    Python, YOLO, scikit-learn, pandas

    code

  3. RGB vs RGB+depth for bunch detection

    2026 · Research, ULM

    Does a depth channel help? I trained YOLO26l, RT-DETR-L and RF-DETR-L on RGB and on 4-channel RGB+D, then tried a two-stage setup (find bunches first, classify ripeness second). About 80 logged experiments. One of the findings was a temporal domain shift between data-collection batches.

    PyTorch, Ultralytics, RT-DETR, RF-DETR

    code
